# Project TODO Tracker

Manage the project's TODO list.

## File

`TODO.md` in this directory is the project's task list.

## When adding items

- Add new items under the appropriate section heading, or create a new section if none fits.
- Use `- [ ]` for unchecked items.
- Be specific — describe what needs to change, not just the problem.

## When completing items

- After finishing work that completes a TODO item, check it off: `- [ ]` → `- [x]`.
- If the work only partially addresses an item, leave it unchecked and add a note about what remains.

## When referenced

- If the user asks about TODOs, what's left, or what to work on next, read `TODO.md` and summarize the open items.
- If the user completes a task (via a commit, PR, or direct request), check off the corresponding item.
- When starting work on a feature or fix, check if there's a matching TODO item. If so, mention it and check it off when done.
